# Landing libro gratis · Persuasione Gentile per Chi Viene Sottovalutato

Pagina statica (nessun modulo, nessuna variabile su Vercel): `index.html` + `copertina.jpg`.

## Prima di pubblicare
Apri `index.html`, cerca `DA COMPILARE` e inserisci tra gli apici:
- `LINK_LIBRO`: il link del PDF del libro su Google Drive, condiviso come «Chiunque abbia il link → Visualizzatore» (mai Editor).
- `LINK_REGALI`: l'indirizzo della web app dei bonus (es. https://kit-persuasione-gentile.vercel.app).
- `ASIN_LIBRO`: l'ASIN di Persuasione Gentile su Amazon.it appena il libro è pubblicato. Finché è vuoto, i pulsanti «Lascia una recensione su Amazon» restano nascosti.

## Pubblicazione
GitHub → nuovo repository → carica `index.html` e `copertina.jpg` → Vercel → Add New → Project → importa → Deploy.

## Regole Amazon sulle recensioni
Libro e regali si scaricano senza condizioni. La recensione è chiesta solo dopo la lettura, sincera e facoltativa, senza screenshot né verifiche. Non aggiungere passaggi che leghino libro o regali alla recensione: Amazon vieta le recensioni incentivate.
